## 第一章 心理重建——拒绝「赌徒」博弈

> 理财不是一夜暴富的神话，而是一场漫长的长跑。

### 第一节 10 万元的「脆弱性」与「可能性」


**10 万的心理阈值**

- 10 万是散户最危险的「心理阈值」，也是普通人一寸一寸从现实里死磕出来的「人生第一桶金」
- 面对带着血汗温度的本金，本书撕开资本市场底层真相：机构降维打击、量化机器的隐秘镰刀、散户「梭哈」背后的致命幻觉

**A 股的规则不对称**

- 主板涨跌幅约 **10%**，创业板、科创板约 **20%**
- 量化机构「撤单在一毫秒内执行」——你连它们什么时候准备撤单的背影都看不见

**两种人生剧本**

- ❌ 错误：「一个月翻倍，一年后盆满钵满，炒掉画大饼的老板，实现阶层跨越」
- ✅ 正确：「在台下冷静观察，等表演结束、满地都是错估的红包时，弯下腰去安安稳稳捡钱的人」（112 人划线）

**补充笔记：流动性陷阱**

> 划线：「流动性陷阱」
>
> 想法：凯恩斯在《就业、利息和货币通论》中提出。利率降到足够低时，人们对货币需求的利率弹性趋向无限大；增货币供应无法降低利率、刺激投资。
>
>

### 第二节 心理账户与「欢乐豆」幻觉


**心理账户（Mental Accounting）——理查德·塞勒**

> 人类在金钱认知上的原罪：钱是一样的钱，但装进不同的心理账户后，它的重量就变了。（234 人划线）
- 大脑不会把所有钱看成等价的一般等价物
- 潜意识建立「看不见的抽屉」，不同来源、用途的钱有不同的「花钱态度」和「痛觉阈值」
- 现实里是「葛朗台」，股市里变成「沙特王子」

**斯金纳箱与梭哈**

- 老虎机底层：**随机的不固定奖励**（Variable Ratio Reinforcement）
- 梭哈迎合大脑「图省事」的本能；套利、资产配置、安全边际、纪律执行，都需要耗能的「前额叶」主导
- 「才跌 3 个点，不卖就不算真亏，过几天反弹就回本」——典型的损失回避自我欺骗

**梭哈 = 心理懒惰的遮羞布**

> 你用勤奋的「战术动作」（每天 5 小时盯 K 线），来掩盖懒惰的「战略思维」（拒绝建立抗风险的财富系统）。（102 人划线）

### 第三节 套利思维：10 万的王道是「尽量求稳」


**容错率：被刻意隐瞒的物理常量**

> 投资策略，从来都不是由你的胆量决定的，而是由你的资金体量决定的。（70 人划线）
- 10 万加杠杆满仓，像拿木棍的小孩站在重装坦克履带前
- 「不亏钱的平均收益」不是平庸，而是**稀缺的优秀**（72 人划线）

**套利思维定义**

> 在市场的夹缝中尽可能去「捡漏」，利用一切可以利用的规则机会，多赚一点绝对确定性的钢镚。

## 第二章 固收底盘的「排雷」与挑选艺术


### 第一节 走出误区：买债基 ≠ 存银行


**债基的两台收益引擎**


| 引擎       | 说明                                 |
| -------- | ---------------------------------- |
| **票息收益** | 借出的固定利息，像心脏起搏器稳定输送；不管股市涨跌，按时还息就有收益 |
| **资本利得** | 低买高卖的价差；卖出价低于买入价 = 资本损失            |


**补充笔记：资本利得**

> 中国内地暂免征收个人资本利得税；美国等成熟市场按比例税率征税。

**债基 vs 存银行的本质**

- 降息周期里，债基有「四两拨千斤」的力学——利率下行，债券价格上涨
- 买债基不等于存银行：净值会波动，存在回撤

### 第二节 投资账户最坚实的基础：纯债基金


**定位**

> 纯债基金不是用来发财、跨越阶层的。核心使命：存放「随时要用、不能亏损」的保命钱。

**基础概念**


| 概念       | 定义                       |
| -------- | ------------------------ |
| **回撤**   | 买入后最多能亏多少                |
| **市场利率** | 社会资金成本的「基准尺子」；纯债收益主要取决于此 |
| **债券本质** | 国家或大企业的借条                |
| **认知错位** | 用错误框架理解产品，导致行为偏差         |


**债券类型**


| 类型       | 特点                         |
| -------- | -------------------------- |
| **利率债**  | 国债、国开行等政策性银行债；国家信用背书，基本不违约 |
| **信用债**  | 企业/城投发行；有违约风险，收益更高         |
| **同业存单** | 银行间定期存款凭证                  |


**信用下沉**

> 为追求高收益，主动降低对借款人信用资质要求——金融圈专用术语。

**四大评级机构**：中诚信、联合资信、大公国际、东方金诚


**纯债基金 5 条筛选规则**


```plain text
规则 1：审视持有人结构 → 机构占比 ≥ 60%
规则 2：警惕规模短期异常暴增
规则 3：拆解持仓结构 → 警惕「信用下沉」与「流动性牺牲」
规则 4：观察最大回撤与修复能力
规则 5：优先选择「大厂」固收团队
```

> 永远记住：做投资，**安全第一**。

**补充笔记**

- **计提减值**：按谨慎性原则，对账面价值高于可收回金额的资产预先认亏
- **认知错位**：因经验、情绪、角色差异产生的理解偏差

### 第三节 一级债基与可转债


**一级债基**

- 主要投债券市场，**不能直接在二级市场买股票**
- 规模舒适区间：**50 亿 ~ 100 亿**
- 筛基核心指标：**可转债仓位比例**

**可转债：债券与股票之间的变体**


| 特性   | 说明                          |
| ---- | --------------------------- |
| 下跌保护 | 可能跌到 100 元附近就跌不动            |
| 下修条款 | 下修空间充足、无破净隐患时，下修 = 变相「送红包」  |
| 强赎条款 | **生死线**：触发强赎 → 立刻卖出或转股，不可试探 |


**基金性价比双指标**


**1. 卡玛比率（Calmar Ratio）——看「抗跌」**


```plain text
公式：区间年化收益率 ÷ 区间最大回撤

> 3.0   极优（每回撤 1% 赚 3%+）
1.5~3.0 良好（优质固收+常见区间）
0.5~1.5 及格
< 0.5   较差
```


**2. 夏普比率（Sharpe Ratio）——看「波动」**


```plain text
公式：（年化收益 - 无风险利率）÷ 波动率

> 1.5   极佳
1.0~1.5 良好
0.5~1.0 一般
< 0     连存款都没跑赢
```


⚠️ 只在**同类基金间**比较；建议看 **3~5 年**长周期。

### 第四节 二级债基三大门派


| 门派      | 特征        | 适合人群        |
| ------- | --------- | ----------- |
| **赛道型** | 激进单边押注    | 高风险偏好       |
| **画线派** | 稳字当头「老黄牛」 | 稳健型（10 万主力） |
| **量化型** | 没有感情的机器   | 管不住手的震荡市    |


**画线派筛选：定量 + 定性**


| 指标      | 标准                  |
| ------- | ------------------- |
| 近三年最大回撤 | **< 5%**（生死线）       |
| 净值修复时间  | 越短越好                |
| 收益回撤比   | 越高越好                |
| 机构持有人占比 | 跟着聪明钱               |
| 债券持仓    | 国债、政金债、大型金融债霸屏      |
| 权益中枢    | **10% 上下** = 保守     |
| 可转债仓位   | 股票不多但转债仓位大 → 进攻弹性仍强 |


**量化型识别**

1. 基金经理来自「量化投资部」或「指数与量化投资部」
2. 前十大个股极其分散，「摊大饼」广度选股

**补充：损失厌恶效应**

> 卡尼曼 & 特沃斯基：同量损失的痛苦是收益快乐的 **2~2.5 倍**。

## 第五章 风险护航


### 第一节 警惕「霸榜」诱惑


撕开互联网理财平台的销售潜规则——榜单排名 ≠ 产品质量。


### 第二节 A/C 份额与首发盲盒


A 类长期持有费率低；C 类短期灵活；首发基金 = 盲盒，缺乏历史数据。


### 第三节 亏麻了怎么办？


**沉没成本**：已经发生、无论怎么挣扎都永远无法收回的损失。


**决策原则**：问「如果今天空手，我还会买这只基金吗？」

## 附录 C：LOF 限额套利全流程


**对应章节**：第三章 · 第一节


**在 5-3-2 框架中**：3 万「套利仓」核心手艺


### C.1 套利原理


LOF 同时有两个「柜台」：


| 柜台     | 价格   | 操作      |
| ------ | ---- | ------- |
| **场外** | 基金净值 | 申购 / 赎回 |
| **场内** | 交易价格 | 像股票一样买卖 |


**溢价套利**：场内价 > 净值 → 以净值申购，以溢价卖出。


### C.2 全书三步框架


```plain text
第一步：获取资质 → 套利友好型券商 + 特权通行证
第二步：锁定猎物 → 组装「监控雷达」
第三步：机械化操作 → 避开通道陷阱，极速收割
```


### C.3 第一步：获取资质

- 深市 LOF（**16 开头**）支持跨账户加挂「**多开**」——突破单账户限购
- 向客户经理确认：场内直接申购、申购费折扣、卖出佣金（书中约 **0.03%**）
- **LOF 场内卖出免印花税**

### C.4 第二步：锁定猎物


**监控雷达三件套**


| 工具              | 定位          | 用途           |
| --------------- | ----------- | ------------ |
| **集思录**         | 专业深度雷达（最实用） | 溢价率、申购状态、成交额 |
| **东方财富 / 天天基金** | 后方情报中心      | 公告、限额变动      |
| **主力券商 APP**    | 贴身近战瞄具      | 下单、持仓        |


**猎物筛选四关**


| 关卡   | 标准                 | 不达标  |
| ---- | ------------------ | ---- |
| 溢价率  | **≥ 10%**（至少 > 8%） | 不碰   |
| 申购状态 | **开放申购**           | 废单   |
| 基因代码 | **16 开头**          | 无法多开 |
| 流动性  | 日成交 **≥ 500 万**    | 踩踏风险 |


**黄金决策期**：**14:45 ~ 14:50**


### C.5 第三步：机械化操作


⚠️ 核心分水岭

> **别把「场内买入」当成「场内申购」！**

| 操作         | 评价         |
| ---------- | ---------- |
| **场内直接申购** | ✅ 首选（极速通道） |
| **场内买入**   | ❌ 不是套利入口   |
| **跨系统转托管** | ❌ 强烈不建议    |

> 极速通道百元只赚 9 元；走错老路通道，直接亏损。

### C.6 标准操作流程


```plain text
T 日 14:45 前
  1. 集思录筛选：溢价≥10%、16开头、日成交≥500万、开放申购
  2. 复核基金公司最新申购限额公告
  3. 计算：溢价率 − 申购费 − 佣金 − 滑点 > 0？

T 日 14:45 ~ 14:50
  4. 券商 APP → 场内基金 → 场内申购（不是买入！）
  5. 有限购：16开头可「1拖6」多账户申购

T+N 日（份额到账）
  6. 二级市场卖出（免印花税，约 0.03% 佣金）
  7. 利润 = 卖出价 − 申购净值 − 各项费用
```


### C.7 成本速算


| 项目   | 数据            |
| ---- | ------------- |
| 印花税  | **0**         |
| 卖出佣金 | 约 **0.03%**   |
| 申购费  | 向券商确认（通常可打一折） |


### C.8 书中三个警示案例


| 案例             | 教训                     |
| -------------- | ---------------------- |
| 标普 500 LOF     | 「一日游」溢价扼杀 40% 美梦       |
| 标普信息科技 LOF     | AI 狂飙下的「外汇饥渴症」         |
| 白银 LOF（161226） | 2025 年 12 月，套利史上最惨烈的转折 |


### C.9 LOF 套利检查清单


```plain text

□ 确认「开放申购」（基金公司公告为准）
```

## 附录 D：纯债基金 5 条规则实操手册


**在 5-3-2 框架中**：5 万「压舱石」核心配置


### D.0 选基前必读


**岗位职责**：

> 纯债基金核心使命：存放「随时要用、不能亏损」的保命钱。

**收益预期**：

> 普通优质纯债，目前利率环境下年化约 **2.5% ~ 3%**。

**收益双引擎**


| 引擎                 | 确定性   |
| ------------------ | ----- |
| **票息收益**（固定利息）     | 高     |
| **资本利得**（利率下行债券涨价） | 中，有波动 |


### D.1 实操总流程


```plain text
选基前 → 拉季报/年报 → 5条规则逐条过筛 → 小仓位试投 → 每季跟踪
```


### D.2 规则一：审视持有人结构


**标准**：机构占比 **≥ 60%**


**红灯**：个人 **≥ 90%** → 赶紧跑，头也不要回地跑。


**操作路径**


```plain text
支付宝/天天基金 → 基金档案 → 概况·持仓·规模·分红 → 规模份额 → 持有人结构
```


| 检查项  | 合格    | 淘汰    |
| ---- | ----- | ----- |
| 机构占比 | ≥ 60% | < 60% |
| 个人占比 | < 40% | ≥ 90% |


---


### D.3 规则二：警惕规模异常暴增


**标准**：警惕规模**短期内异常暴增**。


**原因**：被迫下沉资质买流动性差的企业债，或躺平现金。


**操作**


```plain text
基金档案 → 规模份额 → 查看近 4 季度规模曲线
```


| 检查项  | 合格    | 淘汰        |
| ---- | ----- | --------- |
| 规模趋势 | 平稳缓增  | 单季暴增 50%+ |
| 体量   | > 5 亿 | 迷你基 + 高收益 |


---


### D.4 规则三：拆解持仓结构


**标准**：警惕「**信用下沉**」与「**流动性牺牲**」。


**关键概念**


| 概念       | 说明                 |
| -------- | ------------------ |
| **信用下沉** | 为高收益降低借款人信用要求      |
| **正回购**  | 垃圾债质押加杠杆；资产贬值 → 踩踏 |
| **障眼法**  | 毒药包装在「买入返售金融资产」科目下 |
| **久期**   | 长期债券占比高 = 博弈利率     |


**检查清单**


| 检查项  | 合格         | 淘汰         |
| ---- | ---------- | ---------- |
| 债券评级 | AAA、AA+ 为主 | 大量 AA 以下   |
| 买入返售 | 占比正常       | 异常高        |
| 久期   | 接近同类       | 显著偏高 + 高收益 |
| 正回购  | 无或低        | 大量出现       |


---


### D.5 规则四：最大回撤与修复


**标准**


| 基金类型      | 最大回撤参考          |
| --------- | --------------- |
| **短债基金**  | **0.2% ~ 0.5%** |
| **中长期纯债** | **1% ~ 1.5%**   |


**操作**


```plain text
基金档案 → 历史业绩 → 最大回撤 → 对比同类 → 净值修复时间
```


| 检查项  | 合格   | 淘汰      |
| ---- | ---- | ------- |
| 最大回撤 | 在区间内 | 远超同类    |
| 修复时间 | 越短越好 | 半年以上未修复 |


---


### D.6 规则五：大厂固收团队


**标准**：优先选择头部基金公司固收团队。


**原因**（33 人划线）：大厂有私人交情，能提前安全撤离；散户成接盘侠。


| 维度   | 优先        | 谨慎     |
| ---- | --------- | ------ |
| 基金公司 | 头部固收大厂    | 不知名小厂  |
| 团队   | 多人、管理规模大  | 单人、无历史 |
| 经理   | 固收从业 5 年+ | 频繁更换   |
