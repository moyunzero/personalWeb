智能体：一种**能够推理、规划并与环境互动的 AI 模型** 。


我们称它为Agent，因为它具有_自主性_ ，也就是它能够与环境互动。


_**智能体是一种利用人工智能模型与环境交互以实现用户定义目标的系统。它结合了推理、规划和行动执行（通常通过外部工具）来完成任务。**_


可以将Agent视为由两个主要部分组成：

- **The Brain (AI Model)**
    - 这里是所有思考发生的地方，人工智能模型**负责推理和规划 ，**它会**根据情况决定采取哪些行动** 。
- **The Body (Capabilities and Tools)**
    - 这部分内容代表了Agent**能够执行的所有操作** 。

智能体**能够执行的动作范围**取决于它所**配备的**机能。例如，由于人类没有翅膀，他们无法执行“飞行” **动作** ，但他们可以执行“行走”、“奔跑”、“跳跃”、“抓取”等**动作** 。


## **“能动性”的范畴**


根据这一定义，Agents存在于一个不断增强的能动性连续谱系中：


**智能体代理级别（Agency Level）**


| 代理级别 | 描述                    | 专业名称                        | 示例模式                                               |
| ---- | --------------------- | --------------------------- | -------------------------------------------------- |
| ☆☆☆  | 智能体输出对程序流程无影响         | **Simple Processo**简单处理器）   | `process_llm_output(llm_response)`                 |
| ★☆☆  | 智能体输出决定基本的控制流         | **Router**路由器）              | `if llm_decision(): path_a() else: path_b()`       |
| ★★☆  | 智能体输出决定函数执行           | **Tool Calle**（工具调用器）       | `run_function(llm_chosen_tool, llm_chosen_args)`   |
| ★★★  | 智能体输出控制迭代和程序继续执行      | **Multi-step Agent**（多步智能体） | `while llm_should_continue(): execute_next_step()` |
| ★★★★ | 一个智能体工作流可以启动另一个智能体工作流 | **Multi-Agent**（多智能体）       | `if llm_trigger(): execute_agent()`                |

- **代理级别（Agency Level）**：指大型语言模型（LLM）驱动的智能体在系统中拥有的自主决策和控制能力等级，从最低的“无流程影响”到最高级的“多智能体协同”。
- 星级越高，智能体的**代理性（Agency）**越强，对程序控制权越大。

## **为智能体使用哪种类型的 AI 模型？**


智能体中最常见的 AI 模型是 LLM（大型语言模型），它以**文本**作为输入，并输出**文本** 。


著名的例子包括 **OpenAI** 的 **GPT-4** 、 **Meta** 的 **Llama** 、 **Google** 的 **Gemini** 等。这些模型都经过海量文本训练，具有良好的泛化能力。

> **可以使用能够接受其他输入的模型作为智能体的核心模型。例如，视觉语言模型（VLM），它类似于语言语言模型（LLM），但也能理解图像作为输入。**

## **人工智能如何对其环境采取行动？**


LLM 是很棒的模型，但**它们只能生成文本** 。


HuggingChat、ChatGPT 和类似应用程序的开发者实现了额外的功能（称为**工具** ），LLM 可以使用这些功能来创建图像。


## **智能体可以执行哪些类型的任务？**


agent可以执行我们通过**工具**实现的任何任务来完成**操作** 。


例如，如果我编写一个智能体作为我电脑上的私人助理（类似 Siri），并让它“给我的经理发邮件，请求推迟今天的会议”，我可以给它一些发送邮件的代码。这将是智能体在需要发送邮件时可以使用的一个新工具。我们可以用 Python 来编写它：


```javascript
def send_message_to(recipient, message):
    """Useful to send an e-mail message to a recipient"""
    ...
```


将会看到，LLM 会在需要时生成代码来运行该工具，从而完成所需的任务。


```javascript
send_message_to("Manager", "Can we postpone today's meeting?")
```


**工具的设计至关重要，对代理的质量有着巨大的影响** 。有些任务需要专门设计的工具，而另一些任务则可以使用诸如“网络搜索”之类的通用工具来解决。

> _**请注意， 操作与工具并不相同 。例如，一个操作可能需要使用多个工具才能完成。**_

### **示例 1：个人虚拟助理**


像 Siri、Alexa 或 Google Assistant 这样的虚拟助手，在代表用户使用数字环境进行交互时，会充当agent的角色。


它们接收用户查询，分析上下文，从数据库中检索信息，并提供响应或发起操作（例如设置提醒、发送消息或控制智能设备）。


### **示例 2：客户服务聊天机器人**


许多公司部署聊天机器人作为代理，以自然语言与客户互动。


这些代理可以回答问题、指导用户进行故障排除步骤、在内部数据库中打开问题，甚至完成交易。


他们预先设定的目标可能包括提高用户满意度、缩短等待时间或提高销售转化率。通过与客户直接互动、从对话中学习并随着时间的推移调整响应方式，他们展现了代理工作的核心原则。


### **示例 3：电子游戏中的 AI 非玩家角色**


由 LLM 驱动的 AI 代理可以使非玩家角色 (NPC) 更加动态和不可预测。


它们不再遵循僵化的行为树，而是能够**根据情境做出反应，适应玩家的互动** ，并生成更加细致入微的对话。这种灵活性有助于塑造更加生动、引人入胜的角色，并随着玩家的行为而发展演变。


总而言之，智能体是一个使用人工智能模型（通常是逻辑逻辑模型）作为其核心推理引擎的系统，其功能是：

- **理解自然语言：** 能够以有意义的方式理解和回应人类指令。
- **推理和计划：** 分析信息，做出决策，并制定策略来解决问题。
- **与环境互动：** 收集信息，采取行动，并观察这些行动的结果。
